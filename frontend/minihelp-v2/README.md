已扩展客户资料、商品与订单、设置与权限页面；保留 V2 的配色、导航、客服工作台和客户咨询。八个管理业务页面支持数据显示设计、展示样例和实时查询，管理操作复用当前项目已有接口。

本目录于 2026-09-30 从 Minihelp V2 原型复制到智能客服项目，保留原有界面、交互、资源和设计文档。通过后端 `/v2/` 入口运行时，可接入本项目现有接口。

## 启动预览

无需安装依赖。从智能客服项目根目录，在 PowerShell 中运行：

```powershell
& .\frontend\minihelp-v2\start.ps1
```

打开 <http://127.0.0.1:18878/#/knowledge>。退出时在运行服务的终端按 `Ctrl+C`。服务停止后重复上面的命令即可。端口被占用时可运行 `& .\frontend\minihelp-v2\start.ps1 -Port 18881`，并访问对应端口。

也可直接在本目录运行 `python preview_server.py --port 18878`。预览服务关闭 HTML 与资源缓存，刷新时始终读取当前文件，避免不同浏览器继续显示旧版页面。

也可直接双击 `index.html` 查看，但使用本地 HTTP 服务可获得稳定的相对路径和地址栏页面定位。
