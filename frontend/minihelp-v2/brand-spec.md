# Minihelp V2 · 视觉规范

V2 在 V1 基础上补齐已规划的客户资料、商品与订单、设置与权限页面。当前模式为 **Extension**：沿用配色、字体、像素猫资产、表格与弹窗样式；客户页采用列表与详情并排，订单使用紧凑表格，设置按职责分组。保留现有后台模块与客服流程，新增窄屏文字菜单和顶层页面定位。V1 独立保留，可随时对照。

## Design Read

- 产物：客户与客服原型、原有后台及客户资料、商品订单、设置页面；全部数据均为示例。
- 受众：客户、客服、主管和管理员；桌面工作台优先，客户页兼顾移动设备。
- 设计模式：Extension，保留既有导航标签和暖白、深绿基调；桌面优先、窄窗纵向排布。
- 感受：亲和、克制、适合长时间阅读；客户页更温暖，工作区更紧凑。
- 本轮保护边界：不替换原项目页面，不改业务协议，不接入外部服务。

## 可访问性与响应式约定

原生 button、label、dialog；明确可见焦点；状态同时使用文字；输入支持键盘和中文输入法。移动端主要按钮至少 44 px 高。减少动态效果时关闭过渡。客户资料在窄窗口可从标题栏打开。

本原型已进行代码和本地资源检查；未以此宣称完整浏览器兼容或生产可访问性验收。
