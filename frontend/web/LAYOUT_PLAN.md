# Web V2 管理后台排版完善

2026-10-02：依据 5173 Vue 页面与 8000 原版页面的同尺寸对比实施。当前阶段：本轮排版实现与可用环境下的验收完成；数据库在线业务验收未覆盖，见文末。

## 范围与设计约定

- 保留 V2 深绿侧栏、暖白背景、现有导航、品牌图标和路由。
- 调整管理后台的信息层级、排版、数据可视化与入口文案；不改后端逻辑、API 契约、真实作业和审核流程。
- 主内容用 14px 正文、12–13px 辅助信息、26–30px 读数；紧凑边距，8–10px 圆角，已有配色，不新增动效。
- 保留所有真实指标、未知/失败状态、统计口径、表单字段和启动前核对。长说明允许折叠，异常仍直接可见。
- 客服/客户视角不受管理布局样式影响。原版 `app/static`、旧版 `frontend/minihelp-v2` 与用户未跟踪文件不修改。

## 验证边界与风险

- 本地 MySQL/Milvus 和分类器在线状态以当次检查为准；断连时不得用虚构数据补齐。未恢复依赖时，知识/审核真实数据行验收明确留待后续。
- 页面交互验证不运行训练、评测、入库、向量化或审核发布，避免改变用户数据。
- 最高风险是共用 CSS 影响其他视角；样式限定到管理外壳/数据页，验证客服视角。
- 不自动提交或推送 Git；所有改动保留为可检查的工作区 diff。
